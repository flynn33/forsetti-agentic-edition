## Objective

Realign every active Apple-specific governance surface in Forsetti Agentic Edition with the supplied Forsetti Framework for Mac and iOS 0.1.5 contract, while retaining the existing 0.1.3 profile as an explicitly selectable compatibility profile and leaving Windows governance behavior unchanged except where shared validation must become edition-aware.

## Business Reason

Project Bifrost requires Forsetti Agentic Edition to govern Raven Forge Apple development against the current Forsetti runtime contract. Continuing to default to 0.1.3 would permit stale dependency, manifest, capability, runtime, bootstrap, and verification assumptions to enter later Bifrost integration work.

## Downstream Impact Assessment

Affected consumers include task-contract authors, Apple project bootstrap users, local validator users, bundle consumers, documentation readers, and Apple agents selecting edition profiles. Existing consumers pinned explicitly to Apple 0.1.3 remain supported through the retained versioned profile. New/default Apple initialization and templates select 0.1.5.
